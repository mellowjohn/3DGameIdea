# The Squire (legacy title)

**Squire** was the prior display name for the melee starting archetype.

Canon starter name is now **Ashfell Blade** ([ashfell-blade.md](ashfell-blade.md)) under [DEC-0044](../decisions/index.md#dec-0044-starting-archetype-lane-orgs-and-rename). Home org: **House Ashfell**.

See [Character Creation](character-creation.md) for the full starting triad.
